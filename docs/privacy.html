Privacy Policy: 90s Gaon Chronicles Uploader

Last updated: September 2026

The 90s Gaon Chronicles Uploader ("the app") is a personal automation tool operated by the owner of the 90s Gaon Chronicles YouTube channel. It is used only to upload that channel's own videos.

What data the app accesses

With the channel owner's permission (Google OAuth), the app uses the YouTube Data API to upload videos, set thumbnails, and add videos to playlists on the owner's own YouTube channel. It requests only the youtube.upload and youtube scopes.

What data the app stores

The app stores the OAuth credentials as encrypted secrets in the owner's private GitHub repository, plus the IDs, titles, descriptions and hashtags of videos it has uploaded. It does not collect, store, sell or share any data about viewers or other YouTube users.

Third parties

Video notes may be sent to Anthropic's Claude API to write video descriptions. No Google user data is shared with any other party. The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements. The app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
